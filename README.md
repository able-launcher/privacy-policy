# Privacy Policy for Able Launcher

**Effective Date:** October 1, 2026

Able Launcher ("the Application") is an Android home screen replacement application developed and maintained by the Able Launcher team. This Privacy Policy outlines our practices regarding data privacy, user information, and device permissions.

### 1. Information Collection and Storage
Able Launcher does not collect, track, transmit, or sell any personal data, usage analytics, or device identifiers. All configuration data, home screen layouts, and user preferences remain stored strictly on your local device. The application operates entirely offline and connects to no external servers.

### 2. Device Permissions and Usage
The Application requests specific Android system permissions strictly to provide core launcher functionality:

* **Query All Packages (`android.permission.QUERY_ALL_PACKAGES`):** Used exclusively to detect, index, and launch applications installed on your device within the app drawer and home screen. This information is processed in-memory locally on your device and is never stored off-device or transmitted.
* **Accessibility Service (`android.permission.BIND_ACCESSIBILITY_SERVICE`):** An optional service used solely to expand the notification shade when you perform a downward swipe gesture on the home screen. It does not monitor keystrokes, read on-screen text, track user interactions, or transmit data.
* **Notification Listener Service (`android.permission.BIND_NOTIFICATION_LISTENER_SERVICE`):** An optional service used solely to read active notification counts to display notification badges on app icons. Message contents, sender identities, and notification bodies are never read, stored, or transmitted.

### 3. Third-Party Services
The Application contains no third-party software development kits (SDKs), advertising libraries, or external analytics frameworks.

Any updates to this policy will be published directly to this page with an updated effective date.
